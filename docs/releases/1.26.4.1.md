# sysm 1.26.4.1 — Q4 2026 Notes and Skill Fix Release

This revision fixes `notes show` on macOS 27, which reported every note as not found. It also ships a Claude skill bundle that matches this release. The bundle in 1.26.4.0 still described v1.12.0.

## Fixes

- `notes show` works on macOS 27. On macOS 27.0, it printed "Note '<id>' not found" for every note, including notes that `notes list` returned with that ID. Notes rejects the chained AppleScript expression `name of container of n` with error -1728 or -1700, and `notes show` reported that error as a missing note. It now reads the note's folder first, then the folder's name.
- The `sysm.skill` release asset describes this release. The skill is now built from a reviewable source tree. If the committed bundle differs from that source or names the wrong version, CI fails. The bundle now documents the `appstore`, `focus`, and `language` commands, and it corrects the tag color table, which listed 1 as red. 1 is gray. It also documents the newer options for `calendar`, `reminders`, `notes`, `mail`, and `photos`.

## Compatibility

- No command, option, or output format changes.
- The minimum macOS version remains 26.

## Validation

The `notes show` fix includes a unit test that fails on the old script. The changes passed debug and release builds, 818 unit tests, the skill bundle check, and DocC validation on macOS 26 with Xcode 26.6. The same 818 tests passed on the Xcode 27 preview runner. On macOS 27.0 (26A428), `notes show` returned notes that 1.26.4.0 reported as not found.
